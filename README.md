# FPS ARENA

Браузерный тактический шутер. Автор и владелец — [918web](https://github.com/918web).

Три режима: бой с ботами (до 60 противников, три сложности, дефматч и захват
флага), дуэль 1×1 до пяти побед, командный бой 10×10 с автобалансом.

Девять стволов: АКМ, АК-74, M416, SCAR-H, СВД, MP5, M870, Glock-18, Desert Eagle.
Съёмная обвеска: пять типов прицелов, глушитель, дульные устройства, лазер, фонарь,
передняя рукоять, сошки, три варианта магазинов.

рендера, физики, мира, ai, ui и звука — ещё не залит, без него `npm run build` не соберётся.
Полный исходник собирается в архив `fps-arena-x.zip`.

## Как устроен арсенал

Геометрия разделена на две части, и это сделано намеренно:

- `src/arsenal/models/specs.js` — чистые числа и чистые функции. Ресивер, ствол,
  цевьё, магазин, приклад, линия прицеливания и все точки крепления. Здесь нет
  three.js, поэтому всю разметку девяти стволов можно проверить тестами без браузера
  и без видеокарты.
- `src/arsenal/models/build.js` — превращает одну спецификацию в реальную геометрию.

Семь разных архитектур, а не один силуэт с разными цифрами: `ar` (раздельные
ресиверы), `ak` (газовая трубка над стволом, крышка, боковая планка),
`battle` (монолит и складной приклад), `dmr` (длинный ствол, дерево, рамочный
приклад), `smg` (трубчатый ресивер), `pump` (подствольный магазин, подвижное
цевьё на тягах), `pistol` (затвор на рамке).

## Режимы и сеть

`src/modes/rules.js` — таблицы без three.js: три сложности, четыре волны гарнизона,
константы захвата флага, таблица очков. `src/modes/match.js` — машина матча
(раунды, серии, автобаланс, MVP), тоже без движка — тест прогоняет целый
десятиминутный матч в node.

`src/net/protocol.js` — словарь протокола и конструкторы кадров,
`src/net/index.js` — сокет, реконнект и чужие игроки. Режим с ботами сокет не
открывает вообще. Состояние уходит 20 раз в секунду, чужие игроки
интерполируются на 100 мс позади свежего кадра.

`server/main.py` — FastAPI-релей: лобби, комнаты, реконнект и раздача собранного
билда. Счёт и конец матча считает сервер, а не клиент.

## Меню и запуск матча

`src/shell/menu.js` рисуется до того, как загружен three и движок: на холодном
сервере первое, что видит игрок, — выбор режима, а не чёрный экран. Выбор
режима решает, как собирается движок: качество картинки, размер гарнизона и
открывать ли соединение вообще.

## Тесты

```
npm test
```

Шесть гейтов: архитектура и арсенал, съёмное железо, верстак, режимы, сеть, меню.
Сборка и запуск в браузере проверяются отдельно (`npm ci && npm run build`),
потому что требуют видеокарты.

## Запуск

```
npm install
npm run dev
```

С сервером:

```
npm run build
pip install -r server/requirements.txt
cd server && uvicorn main:app --port 8000
```

Движок рендера и набор деталей для моделей — открытая база под лицензией MIT;
её файл `LICENSE` едет вместе с кодом движка, как требует лицензия. На саму игру,
механики, арсенал, режимы и дизайн это не влияет.
