# FPS ARENA X — план работ

**База:** процедурный шутерный движок на Three.js r180, 11 подсистем, вся геометрия строится кодом.
**Слой:** механики и арсенал FPS Arena (боты / 1×1 / 10×10, 9 стволов, съёмные прицелы, лазер, фонарь, глушитель, доска оружия).

## Принцип интеграции — «не ломать базу»

База написана под жёсткий контракт (`ARCHITECTURE.md`): подсистема
владеет своей папкой, никто не импортирует чужие модули, всё общение — через
`ctx.get(id)` и события. Поэтому новый код **не переписывает** `src/weapons`,
`src/ai`, `src/ui`, а добавляет свои подсистемы и расширяет базовые в рантайме:

| новая подсистема | id | что делает |
|---|---|---|
| `src/arsenal/` | `arsenal` | 9 стволов FPS Arena на геометрическом ките базы + съёмное навесное |
| `src/modes/` | `modes` | режимы: боты (DM/CTF, 3 сложности), 1×1 (bo5), 10×10 |
| `src/net/` | `net` | WebSocket-клиент протокола FPS Arena (лобби, комнаты, реконнект) |
| `src/shell/` | `shell` | меню выбора режима, доска оружия, табло, итоги матча |
| `server/` | — | FastAPI-релей из FPS Arena, раздаёт собранный билд |

## Этапы

- [x] **0. Разведка.** Прочитан контракт базы, API `weapons`/`ai`/`ui`/`player`/`physics`,
      эталонная модель карабина, статы 9 стволов из исходной игры.
- [x] **1. Данные арсенала.** `arsenal/defs.js` — 9 стволов в схеме базы
      (rpm, баллистика, паттерн отдачи, поза ADS). `arsenal/attachments.js` —
      каталог навесного и чистая функция пересчёта статов.
      *Тест:* `tools/verify-arena.mjs --unit` — схема, диапазоны, совместимость слотов.
- [x] **2. Модели стволов.** `arsenal/models/specs.js` — чистая разметка девяти
      стволов и все точки крепления; `arsenal/models/build.js` — сборщик на ките
      `weapons/parts.js`: семь архитектур (AR, AK, SCAR, СВД, MP5, помпа, пистолет).
      *Тест:* габариты, порядок деталей, все обязательные `nodes` и их форма, бюджет треугольников.
- [ ] **3. Съёмное навесное.** Планки, быстросъём оптики (iron/red dot/holo/3x/ПСО),
      глушитель, лазер (луч + точка), фонарь (SpotLight в viewScene), передняя рукоять, сошки.
      *Тест:* монтаж/демонтаж без утечек геометрии, пересчёт статов, стабильность числа источников света.
- [ ] **4. Доска оружия (gunsmith).** Верстак в мире + экран настройки ствола.
- [ ] **5. Режимы.** Боты (DM/CTF, сложности), 1×1 bo5, 10×10 с автобалансом.
- [ ] **6. Сеть.** Клиент протокола FPS Arena + порт сервера.
- [ ] **7. Дизайн-слой.** Меню/HUD/итоги: собственная типографика, сетка, motion.
- [ ] **8. Общий тест.** Статическая проверка + прогон `npm run build` и
      headless-смоук в CI (в песочнице нет сети → выполняется на GitHub Actions).

## Правила качества (перенесены из базы + дизайн-гайд)

1. Никакого `Math.random()` в геймплее — только `ctx.rng`.
2. Нулевые аллокации в кадре: всё преаллоцировано в `init()`.
3. Всё созданное освобождается в `dispose()`.
4. Число видимых point-light'ов постоянно (иначе рекомпиляция шейдеров).
5. Дизайн: без дефолтного «ИИ-стиля» — никаких фиолетовых градиентов, стоковых
   glassmorphism-карточек и центрированных hero-блоков. Своя сетка, свой ритм,
   анимация только на трансформациях и прозрачности.
